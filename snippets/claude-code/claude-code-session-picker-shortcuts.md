Title: Claude Code Session Picker Shortcuts
Description: Keyboard shortcuts inside the claude --resume session picker.
Tags:
  - claude-code

  - workflow
---

```txt
Ctrl+A      Show sessions from ALL projects on this machine (useful if you forget which dir you started in)
Ctrl+B      Filter to sessions from the current git branch
Ctrl+W      Show sessions from all worktrees of the current repo
/           Search / filter sessions by keyword
Space       Preview session content before resuming
Ctrl+R      Rename the highlighted session
Enter       Resume selected session
Esc         Exit picker
```
